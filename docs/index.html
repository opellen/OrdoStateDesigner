Core Capabilities

Built for Modern Systems Engineering

Everything you need to design, verify, and ship bulletproof state machine architectures.

Full Harel Statecharts

Compound and parallel states, shallow & deep history states, delayed (after) and periodic (every) transitions, targetless transitions, and wildcard event routing.

Live Interactive Simulator

Execute statecharts right on the canvas. Step forward and backward, inspect live context variables, set breakpoints, inject synthetic events, and manually complete asynchronous invocations.

Zero-Qt Generated C++20

Generated transition cores require only the standard library (<variant>, <concepts>). Ideal for embedded devices, gaming engines, and real-time backend services.

Multi-Kernel Shell Isolation

Each open document runs on its own isolated Ordo AppKernel. Crash containment and memory boundaries guarantee one complex diagram never degrades another.

Standard Interoperability

Two-way import and export with XState v5 JSON specifications and W3C SCXML. Export directly to PlantUML for technical design reviews and architectural documentation.

AI Agent & MCP Bridge

Native Model Context Protocol (MCP) server support. Enable AI pair programmers (Claude, Antigravity, Gemini) to inspect state models, arrange layouts, and synthesize machines programmatically.

Clean Separation: Topology vs Implementation

Ordo enforces a strict boundary between machine topology and concrete domain logic. The visual diagram declares states, transitions, and guards; domain callbacks are implemented in pure, testable C++ delegates outside the generated code.

Frequently Asked Questions

Common Inquiries

Does the generated C++ code require any external runtime libraries?
No. The generated transition core and statechart classes rely strictly on the standard C++20 library (<variant>, <concepts>, etc.). There are zero framework headers, macros, or runtime DLL dependencies in emitted files—run it anywhere from embedded systems to game engines.
Can I use the generated C++ code in commercial products?
Yes. The code generator emits code that you own. For complete peace of mind, team compliance, and corporate procurement invoices, our Studio / Commercial tier grants an explicit commercial license free of AGPL copyleft stipulations.
Can I run Ordo State Designer on Linux or macOS?
Yes. The application is written in standard cross-platform C++20 and Qt 6 Widgets. Linux and macOS users can build from source using CMake and Ninja directly from our open-source GitHub repository.
What is the repository's contribution policy?
To maintain architectural cohesion and single-maintainer sustainability, we operate on an issue-driven development model and do not accept unsolicited code Pull Requests. We actively welcome bug reports, minimal reproduction cases, and feature discussions via GitHub Issues.
